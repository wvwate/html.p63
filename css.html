каскадни таблиці стилів: CSS

частково про CSS зазвночалось у попередньому модулі про

рекомендований спосиб додавати стилі для всього сайту - це окремий файл що підключається за допомою тегу link у заголовку сторінкі. суть файлу це послідовне застосування стилів для груп елементів,які потрапляють до селектрів. можна сказати, що кожна команда CSS-файлу має структуру: (знайте все,що відповідає такому-то селектору) {і застосувати до нього данний набір стилів} 

        (знайте все,що відповідає такому-то селектору){
        і застосувати
        до нього данний
         набір стилів
        }

термін "каскадний" стверджує те, що можна наступна команда буде поєднуватись з попереднім.

основни селектори

.celector-table th
селектор значення
* всі елементи
img всі елементи що мають тег <img/>
.middle всі елементи в яких зазначено class=".middle"
всі елементи <th> які знаходЯтчя в середині елементів з class="celector-table". взагалі,пробіл між селекторами означає "в середині", пробілом можуть розділятись і інші виді селекторів. наприклад, "p b " - всі теги <b> в середині параграф (<p>); ".bold .small" - всі елементи з класом "small" в середині елементів з класом "bold"
