каскадні таблиці стилів: CSS

рекомендований спосіб додавати стилі для всього сайту - це окремий файл, що підключається за допомогою тегу link у заголовку сторінки. кожна команда CSS-файлу має структуру:

селектор {
  властивість: значення;
}

термін "каскадний" означає, що наступна команда може поєднуватись з попередньою.

основні селектори

селекторзначення
*всі елементи (рядок: червоний, :nth-child(2))
imgвсі елементи що мають тег <img/> (рядок: помаранчевий, :nth-child(3))
.middleвсі елементи в яких зазначено class="middle" (рядок: жовтий, :nth-child(4))
.selector-table thвсі елементи <th> всередині елементів з class="selector-table" (рядок: зелений, :nth-child(5))
.blueвсі елементи з класом "blue" (рядок: блакитний, селектор класу)
#last-rowєдиний елемент з id="last-row" (рядок: фіолетовий, селектор id)

як це зроблено

кожен рядок має свій колір завдяки різним селекторам: перші чотири рядки вибираються за порядковим номером через :nth-child(), п'ятий - через клас .blue, шостий - через унікальний id. при наведенні мишки рядок темнішає (:hover).
